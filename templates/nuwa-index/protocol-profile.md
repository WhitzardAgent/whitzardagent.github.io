# Private protocol profile

Stable protocol ID: an existing catalogue ID.
Snapshot ID: the exact source snapshot.
State: local-review; model-authored draft; evidence/editorial approval pending.

Record these fields in both languages, with exact source locators and field-level verification status:

- Measurement: the construct and its observable endpoint.
- Task: starting information, objective, environment and actual public example if available.
- Scoring: success/failure, aggregation, repetitions, guidance, pass@k and exclusion rules.
- Conditions: source version, task set, model identity, harness, tools, budgets, attempts, judge and roles. Unknown values remain null.
- Statistics: original numerators and denominators with units, trial counts, intervals, confidence level and method. Do not infer unspecified quantities.
- Validity: controls, negative results, contamination, elicitation, judge error, uncertainty and transfer limits specific to this protocol.
- Usage: a separately labelled model recommendation for the decision this evidence can inform.

Retained catalogue fields and variants are not newly verified source facts. Mark inherited fields and cite their provenance. Keep a bibliography-only or scope-only profile explicitly incomplete instead of generating missing methods. Comparison requires a defined target contrast, reviewed conditions and exact source versions; shared benchmark names do not suffice.
