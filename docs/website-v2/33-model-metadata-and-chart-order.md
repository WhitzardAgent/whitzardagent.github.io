## Parameter-size point encoding — 2026-10-28

Current monitoring release-timeline scatter plots (including Benchmark pages such as MASK) encode disclosed **total** parameters in four fixed diameter bands: tiny ≤4B (8px), small >4B and <40B (12px), medium 40B–150B inclusive (18px), large >150B (26px). Boundaries follow the textual classifications in [Artificial Analysis's open-source comparison](https://artificialanalysis.ai/models/open-source), checked 2026-10-28; their compact 4B–40B wording overlaps, so exact boundary decisions are explicit here. This is an ordinal band encoding, not area proportional to parameter counts or inference compute.

`modelSize.mjs` is shared by ECharts SSR, interactive chart rendering, keyboard descriptions, legend and exports. Only `disclosed` total counts with source metadata qualify; estimates, pending or undisclosed values do not. MoE active counts remain separate in tooltips and metadata. Unknown size uses a fixed10px mark with a dashed outline, retaining the existing condition shape and developer color. Selection thickens the outline without enlarging the point. Size does not alter condition shapes, comparability permission, result values, error bars, dates or links. Bar and condition-matrix views do not encode point size. Archived source-series charts in Methodology retain their historical display grammar.

A compact legend follows the timeline so the desktop default plot remains visible in the initial viewport. It states units (B = billion parameters), fixed-band semantics and disclosed-size coverage among the filtered dated observations. Zero known sizes remains an explicit unknown-coverage state. The legend is hidden in bar/table/matrix views. Tooltip and keyboard descriptions identify each size class and reported total/active counts. SVG export metadata records the size encoding version, per-record class/counts and parameter source references; its visible footer explains bands.
