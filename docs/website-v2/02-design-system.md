# 02｜视觉设计系统

## V4 企业品牌基础（当前基线）

共享基础由 `src/styles/brand-system.css` 统一管理，作用域为 `.brand-site`，避免路由样式加载顺序覆盖字号和布局。内容最大宽度 1360px，章节间距桌面 88–120px、移动端 48–64px。中文使用本地 MiSans，英文使用 Geist；主标题桌面 56–72px、移动端 32–40px，正文 16–18px，信息图标签至少 12px。品牌图使用原创光影与材质，网格、技术仪表和流程图进入具体内容区。导航保留图标与类别，但使用轻量分隔和常规菜单布局。

## 字体

### 中文

- UI、正文、标题与研究引语统一使用现代黑体：`PingFang SC`, `Source Han Sans SC`, `Noto Sans CJK SC`, `Microsoft YaHei`, system sans-serif。

### 英文

- 自托管 `Geist Sans Variable`，数字和实验室元信息可使用系统等宽字体。

### 字体使用限制

- 全站不使用宋体或 Serif；
- 东方感通过网格、留白、颜色与节奏表达；
- Hero 标题字重 600–650，正文 400–500；
- 中文正文行高 1.75，英文正文行高 1.6。

## 圆角与边框

- 普通卡片：16px
- 重点容器：24px
- CTA：999px 或 12px，统一一种风格
- 边框：1px hairline
- 禁止所有卡片使用明显投影
- 仅浮层、导航和主视觉节点使用低透明阴影

## 空间系统

- 页面最大宽度：1200–1240px
- 桌面 section 纵向间距：120–160px
- 移动端 section 间距：72–96px
- Hero 顶部有效空间：120px
- 单段正文最大宽度：680px
- 任何一屏最多一个视觉主角

## 状态视觉

- Allow：玉青 / 玄青
- Sanitize：玉青
- Align：靛蓝
- Degrade：中性蓝灰
- Approve：靛蓝
- Deny：朱砂

状态出现动画应克制、明确：

1. 轻微缩放 0.92 → 1
2. 透明度 0 → 1
3. 120–180ms
4. 不使用弹跳
