## 设计方向

用户已选择“四产品入口＋可切换的宽幅真实界面”。随后明确要求各款展示页面全貌，Gateway 主图必须使用 Overview。样板已获认可。官网产品菜单和页脚均进入首页展位，产品咨询沿用现有联系渠道。

- 保留白泽标志、月白背景、玄青文字、玉青交互重点及现有中英文字体方向。
- 页面面向企业安全负责人、平台团队及研发人员。视觉采用克制的技术产品编辑版式。
- 模式为产品区重新构图，保留全站品牌和路由契约。
- 设计尺度为构图变化 5、动效 1、信息密度 5、真实素材依赖 9、品牌保持 9。
- 以 8px 为基础节奏，正文 16–18px，辅助信息不承担主要说明职责。菜单浮层允许轻阴影，其余区域以间距和细线组织。
- 产品区使用横向四入口。每次展示一款产品的定位、简短价值、三项已核实能力和宽幅截图。窄屏入口排列为两列，界面保持原比例并提供原图入口。
- 单列图文产品菜单保留独立线性图标、产品名、中文定位。产品图标表达类别，不能替代正式品牌标志。
- 不自动轮播，不制作假的运行演示，不用透视倾斜处理界面。

## 首页后续结构

1. 品牌首屏。保留现有品牌主张，缩短无效留白，保留“了解产品”和“联系团队”。
2. 四产品展位。四项职责为代码审计、安全接入、安全运营、安全评测。展示职责关联，不宣称已实现互通或必须组合购买。
3. 企业场景。保留通用办公、开发运维、GUI 智能体、AI 工作流，依据真实功能连接产品。
4. 女娲研究与开放生态。继续承担研究依据和公共成果展示职责。
5. 最新动态与联系入口。沿用当前内容与提交方式。

## 发布范围

- 首页展示四产品 Tabs、定位、三项能力和完整界面首屏。支持键盘切换、片段分享、返回与语言切换。
- 导航和页脚只链接首页展位，不新增独立详情路由。未发布的三款旧命名草稿不进入构建。
- 现有 `/agentguard`、`/gateway` 及英文地址改为静态兼容跳转，旧片段目标保留，详情正文不再发布。
- 公开图片仅包含经过脱敏的完整首屏。整页长图、深层规则和逐用例证据留在本地审阅目录，不复制到公开素材。

- 保持 Astro 静态输出、双语路径、既有内容管线和 GitHub Pages。撤回时可回退本次发布提交。
