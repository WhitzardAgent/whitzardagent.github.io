# NUWA Index — Wiki reading, Methodology and bibliography

Approved implementation: 2026-10-27; local review only. Supersedes the four-entry navigation and repeated Trend maintenance notices.

## Reading contract

Framework · Trend · Research · Benchmarks · Methodology. Methodology is independently addressable via `view=methodology`; legacy Framework `#indicator-register`, `#source-series` and `#ni-methodology` open it. The Framework diagram and definitions stay in Framework. Trend has no Evidence changes block or repeated methodology links.

Methodology presents Sources, Collection, Synthesis, Comparison, Limitations, Acknowledgements and Versions. Credits derive from actual work contributions, model developers and recorded evaluators, link official organization homepages and do not assert partnerships. Retained corrections link the affected records.

## Wiki maintenance

`src/content/nuwa-wiki/<stable-id>.<locale>.md` stores independent editorial prose, case provenance and precise source references. Five bilingual pilots: CyberGym, Cybench, AgentCyberRange, Agentic misalignment, and robot shutdown resistance. Case labels distinguish source examples from descriptions of source protocols. Numerical results remain in the existing catalogue and charts, not copied into the articles.

All Benchmark templates now introduce tasks and measurement before results. Where available, a source-reported run illustrates the measured system, task scope, budget and metric directly from the record. This is labelled a reported evaluation, **not** an individual original test case. Pages with scope-only material are explicitly identified in the audit. Other work pages recompose distinct existing notes into continuous reading sections, removing duplicate lead text; this does not upgrade the depth of source review. Missing substantive material remains in the coverage file rather than being invented.

English and Chinese articles share the stable record ID. Add 1–2 real source examples when public; summarize protected or hazardous task material without operational detail. Keep original authorship, test conditions and interpretation boundaries. New Markdown source refs may reference a source ID or an explicitly titled resource URL, with a locator.

## Bibliography

One page entry per verified publication identity. Existing source IDs and versions remain untouched; the presentation registry records verified alternate publication resources. Palisade robot HTML directly links the matched report PDF: one item preserves the report date 2026-02-11 and webpage publication 2026-02-12. Canonical URL normalization also unifies trailing-slash source identities. Similar titles alone do not justify merging.

References use inline numbered entries, wrapping naturally; mobile stacks entries. Authors, title, dates, resource links and necessary locations appear once. Duplicate “Used for” paragraphs and internal IDs are removed. Old citation anchor aliases remain usable. View-filtered bibliography numbers update contiguously. Source records retain original precise locators and applicability.

## Brand identity

Brand attribution does not establish endpoint identity or release dates. A reviewed reported-family resolver handles explicit model-family names, with conservative support for known wrappers. A Claude Code harness never makes an unidentified model an Anthropic model. Mixed-model and custom systems remain separately identified. Standard and official source charts, table labels and standalone SVGs use the same local marks, aligned to the left of the model name. SVG downloads embed local assets.
