# 01｜品牌战略：东方理性主义

## 品牌定位

**Whitzard**  
AI Agent Security Infrastructure  
智能体安全基础设施

**AgentGuard**  
企业级智能体运行时安全平台

**NVWA Lab**  
Whitzard 背后的前沿 AI 安全研究引擎

**WhitzardAgent**  
开放模型、工具、数据与评测生态

## 核心品牌思想

> 智能体的价值来自自主性。安全的目标，是为自主性建立可信边界。

中文主张：

# 守其边界，行其智能

英文主张：

# Secure autonomy, by design.

## 品牌气质

- 静：留白、低速动画、无视觉噪声
- 界：边界、策略、介入、状态变化
- 序：轴线、网格、层次、连续流程
- 智：动态判断、模型协同、持续进化

英文关键词：

- Calm Intelligence
- Structured Autonomy
- Quiet Confidence
- Eastern Precision

## 东方感的表达原则

### 应使用

- 月白背景，而非大面积纯白
- 玄青和靛蓝，而非霓虹蓝紫
- 玉青用于研究和知识
- 朱砂用于关键决策和 CTA
- 横向轴线、层叠屏风、细线流动
- 中文标题偶尔使用宋体
- 动画像“流动、展开、落印”

### 不应使用

- 祥云、龙凤、山水贴图
- 传统印章按钮
- 赛博朋克代码雨
- 大面积紫色渐变
- 机器人、盾牌、锁的图库插画
- 无意义粒子和 3D 地球
