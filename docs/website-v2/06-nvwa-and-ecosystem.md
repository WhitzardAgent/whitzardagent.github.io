# 06｜NUWA Lab 与开放生态

## V3.4 白泽开放生态

中文访客名称统一为“白泽开放生态”，英文为 `Whitzard Open Ecosystem`。首页和完整生态页均以四项核心能力开场：WhitzardOS、WhitzardEval、Thought-Aligner、MATE。

`qitos`、`QitOS`、`snowl` 与 `snowl-evals` 仅作为内部别名或上游仓库路径。完整生态页按稳定 ID 分组，保留全部公开目录；GitHub 与 Hugging Face 分别展示，AgentGuard 公开仓库继续明确标注社区版。

## NUWA Lab 的角色

首页只需要一句：

> The research engine behind Whitzard.

中文：

> Whitzard 背后的前沿安全研究引擎。

NUWA 页面承担完整研究叙事：

- 定义前沿风险；
- 建设评测与证据；
- 连接全球伙伴；
- 推动标准和治理；
- 将研究转化为安全模型与产品能力。

## NUWA 视觉

- 月白 / 暖纸背景
- 玉青为主色
- 使用更大留白
- 研究标题使用现代无衬线字体
- 首屏必须使用现有女娲 Logo
- 动画更慢、更少
- 不使用 AgentGuard 的朱砂状态标签体系

## Open Ecosystem 页面

按能力分类：

1. Runtime Security
2. Safety Models
3. Evaluation Infrastructure
4. Agent Infrastructure
5. Cybersecurity Agents & Data

每个项目卡片只保留：

- 名称
- 一句话价值
- 状态
- GitHub / Hugging Face / Paper

不要在首页展示完整项目目录。
