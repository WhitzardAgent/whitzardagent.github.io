# 06｜NVWA Lab 与开放生态

## NVWA Lab 的角色

首页只需要一句：

> The research engine behind Whitzard.

中文：

> Whitzard 背后的前沿安全研究引擎。

NVWA 页面承担完整研究叙事：

- 定义前沿风险；
- 建设评测与证据；
- 连接全球伙伴；
- 推动标准和治理；
- 将研究转化为安全模型与产品能力。

## NVWA 视觉

- 月白 / 暖纸背景
- 玉青为主色
- 使用更大留白
- 研究标题可使用 Serif
- 动画更慢、更少
- 不使用 AgentGuard 的朱砂状态标签体系

## Open Ecosystem 页面

按能力分类：

1. Runtime Security
2. Safety Models
3. Evaluation Infrastructure
4. Agent Infrastructure
5. Cybersecurity Agents & Data

每个项目卡片只保留：

- 名称
- 一句话价值
- 状态
- GitHub / Hugging Face / Paper

不要在首页展示完整项目目录。
