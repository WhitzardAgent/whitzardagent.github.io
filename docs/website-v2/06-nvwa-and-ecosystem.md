# 06｜NUWA Lab 与开放生态

## V3.12 NUWA 动态视觉（覆盖旧 Logo 首图规则）

- NUWA 实验室首屏不再把 Logo 作为主视觉，品牌名称以文字锁定，主视觉使用代码原生的“风险证据场”。
- 风险证据场由玉青观测轨道、评测路径、证据节点、治理路径与中央观测孔径组成；抽象图形必须承载研究语义，不做无意义装饰。
- 背景网格缓慢平移，轨道、路径和节点使用不同周期的克制动画，形成持续观测感；进入内容区后使用一次性滚动揭示和细线展开。
- 动画不得遮挡、延迟或替代研究内容；关闭 JavaScript 或启用 `prefers-reduced-motion` 时，完整静态信息仍然可读。

## V3.14 三类语义化 Hero

- 白泽指数采用“前沿风险观测仪表盘”，首屏默认展示 AgentCyberRange，并允许用户切换 Self-Replication 与 OpenDeception；三项内容属于“已发表评测证据”，不得写入正式指数排名或合并为安全总分。
- 每条证据必须保留评测对象、运行配置、风险维度、方法版本、来源与不确定性。论文级阈值不能伪装为精确排名，受控实验结果不能外推为现实部署概率。
- 白泽开放生态采用矩形网格上的开放技术循环：WhitzardOS 构建、WhitzardEval 评测、Thought-Aligner 校准、MATE 审计，并以证据回流闭环结束。
- 关于我们采用“三域汇流”：AgentGuard、女娲实验室与开放生态围绕白泽统一使命相互增强。不得复用公司 Logo 或无语义圆环作为首图。
- `Thought-Aligner` 的能力描述固定为“推理校准模型 / Reasoning alignment model”。

## V3.4 白泽开放生态

中文访客名称统一为“白泽开放生态”，英文为 `Whitzard Open Ecosystem`。首页和完整生态页均以四项核心能力开场：WhitzardOS、WhitzardEval、Thought-Aligner、MATE。

`qitos`、`QitOS`、`snowl` 与 `snowl-evals` 仅作为内部别名或上游仓库路径。完整生态页按稳定 ID 分组，保留全部公开目录；GitHub 与 Hugging Face 分别展示，AgentGuard 公开仓库继续明确标注社区版。

## NUWA Lab 的角色

首页只需要一句：

> The research engine behind Whitzard.

中文：

> Whitzard 背后的前沿安全研究引擎。

NUWA 页面承担完整研究叙事：

- 定义前沿风险；
- 建设评测与证据；
- 连接全球伙伴；
- 推动标准和治理；
- 将研究转化为安全模型与产品能力。
