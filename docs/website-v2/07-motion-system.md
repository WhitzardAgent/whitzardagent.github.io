# 07｜动效与高级交互系统

## V3.13 首页持续环境动效（当前实施基线）

- 首页持续环境动效由低对比坐标网格、玉青色域和边界弧线构成；周期为 `24–40s`，视觉位移不超过约 `10px`。
- 首屏可信边界场允许环形反向缓慢运动、三类轨迹流动和节点低频响应；这些动画不自动切换内容，也不伪造实时状态。
- 章节进入使用 `480–640ms` 的透明度和 `16px` 以内位移，每组错峰 `70–110ms`，每项只出现一次；无 JavaScript 时内容默认可见。
- AgentGuard 业务流约十二秒，进入视区自动播放一次。离开视区、页面隐藏或用户暂停时停止推进，支持继续与重新演示，结束后保持最终处置状态。
- 页面动效控制器只维护可见章节、内容进入、页面可见性与 reduced-motion，不接管滚动，不使用鼠标跟随或持续强发光。
- 移动端保留语义节点并简化空间关系；`prefers-reduced-motion` 下所有内容直接显示稳定终态，关闭持续运动与平滑转场。
- 持续动画只改变 `transform`、`opacity` 与 `stroke-dashoffset`，不引入 WebGL、Canvas、视频或额外动效依赖。

## V3.12 品牌环境动效（覆盖“全站仅一处自动动效”的绝对限制）

- 首页 AgentGuard 业务流仍是全站唯一自动播放的叙事型动效。
- NUWA 首屏允许非叙事型环境动效：背景网格漂移、观测轨道缓慢转动、证据路径流动与节点呼吸；不自动切换内容或伪造实时数据。
- AgentGuard 部署架构允许边界信号与运行时扫描线缓慢移动，用于表达控制持续存在。
- 环境动效必须低对比、周期大于 5 秒，不影响正文阅读，并受 `prefers-reduced-motion` 统一约束。

## V3.11 当前动效约束（覆盖旧首屏系统地图方案）

全站只保留一处叙事性自动动效：中文和英文首页共用的 AgentGuard 业务流。动效沿真实 Agent 循环推进，不使用网络拓扑、无意义粒子、雾化光球或持续发光：

`业务目标 → Agent 规划 → LLM 推理 → 工具调用 → Observation → Agent 再规划 → 外部行动`

每轮约 12 秒，明确呈现敏感字段在外发边界被脱敏、复检后安全继续。页面离开视区或浏览器隐藏时暂停；提供暂停、继续和重新演示；`prefers-reduced-motion` 直接显示最终结果。产品页系统图保持静态，用户交互只用于节点检查。

## V3.10 持续运行时动效

- 环境传播与风险叙事分离：粒子持续流动，风险介入按周期演示。
- 同时可见粒子不超过六个，并用圆形、菱形、方形区分数据、授权和动作影响。
- 离开视区、浏览器隐藏或用户显式暂停时暂停 SVG 时间轴；用户节点检查 10 秒后恢复叙事。
- `prefers-reduced-motion` 直接显示最终介入状态。

## 推荐库

### 保留：Framer Motion / Motion

当前仓库已经使用它，应继续负责：

- Hero 元素入场
- 卡片和按钮微交互
- SVG path 动画
- 状态标签
- 局部 scroll-linked 动画
- reduced motion

### 不再使用：GSAP + ScrollTrigger

V3.9 已移除首页 pinned scrollytelling 和研究—产品滚动动画。研究产品闭环采用 Astro 静态结构与 CSS 微动效，不再为单一章节加载独立动画运行时。

### 新增：Lenis

用于桌面端平滑滚动，并与 ScrollTrigger 同步。

约束：

- 尊重 `prefers-reduced-motion`
- 触摸设备默认使用原生滚动
- 表单、锚点和键盘导航必须正常
- 不使用无限滚动和横向滚动噱头

### 使用 Astro ClientRouter

用于：

- 页面间淡入淡出
- Header 持续存在
- 品牌色在 Whitzard / NVWA 间平滑切换

## 动效分级

### L1 微交互

- 按钮
- 导航
- 标签
- 链接箭头

时长：120–220ms

### L2 内容进入

- 标题
- 说明
- 卡片
- 数据

时长：450–700ms  
位移：8–24px

### L3 叙事动画

- Runtime Trace
- Three Chains
- Research-to-Product Loop

时长由滚动驱动，不自动快速播放。

V3.9 约束：未进入视区的内容不得依赖动画脚本保持隐藏；论文、研究关系与公共影响默认完整可读。

## 东方气质的动效词汇

- 生长：线条沿路径出现
- 展开：内容像屏风轻移
- 收束：风险路径被修正
- 落印：状态标签出现
- 留白：动画结束后保持静止

## 禁止

- 反复循环的强动画
- 鼠标跟随光斑
- 大量浮动卡片
- 快速数字滚动
- 过度弹簧和弹跳
- 全站 WebGL
- 首屏自动播放视频

## V3.14 Hero 动效约束

- 白泽指数、开放生态与关于我们共享月白网格、玉青色域和边界弧线，但分别使用数据仪表、开放拓扑与三域汇流，禁止只替换页面标题而复用同一构图。
- 环境动效周期为 28–48 秒，位移不超过 8px；数据绘制为 600–800ms；交互反馈为 160–240ms。
- 白泽指数的研究面板只能由用户切换，不自动轮播，不滚动数字；支持鼠标、触摸、Tab、方向键、Home 与 End。
- 进入后台或离开视区时暂停 CSS 与 SVG 动效；`prefers-reduced-motion` 直接呈现稳定终态。
- 持续动画只改变 `transform`、`opacity` 或 `stroke-dashoffset`，不引入 Canvas、WebGL、视频或新的运行时依赖。

## V3.5 标签传播动画

- 数据、授权与动作影响采用不同形状、文字和颜色，禁止仅依靠颜色传意。
- 发光状态点沿连续轨迹推进；AgentGuard Gate 在当前边界显示检查、修复、审批或阻断。
- 首次进入视区播放一次，用户操作后停止自动推进；提供暂停与重播。
- `prefers-reduced-motion` 与无 JavaScript 状态直接输出完整结果，不隐藏业务信息。

## V3.6 企业系统地图

- 月白系统地图使用 SVG 路径和三种粒子形状表达数据、授权与动作影响；粒子有文字图例，不以颜色作为唯一信息。
- AgentGuard 玄青边界包裹完整系统，进入视区后播放一次约七秒，结束后停留在最终状态。
- 节点点击后停止自动推进；移动端改为纵向执行路径，不缩小复杂关系图。
- 统一引擎只动画透明度、位移和路径进度；模拟器由用户触发，不自动循环。
