# 05｜AgentGuard 产品页 V3.1

## V3.11 当前产品页结构

- Hero 改为全宽排版，不使用抽象保护对象图或重复产品截图。
- Hero 以简洁文字索引呈现保护范围，并用证据带区分 Enterprise、Community、支持框架、关键介入位置和信任边界内部署。
- 企业系统图为静态优先的节点检查视图，不播放装饰性粒子；完整交互集中在三链引擎和任务模拟器。
- Dashboard 仅在产品界面区出现一次。
- 产品页是保护对象、三链机制、任务模拟、版本差异、框架、部署和现有安全体系关系的唯一归属。

## 页面职责

AgentGuard 只回答产品是什么、如何判断、如何处置、如何接入；企业工作流与采购场景进入解决方案页。

## 页面结构

### 1. Product Hero

- 中文：`智能体运行时安全控制层`
- English: `Control the full agent runtime.`
- 使用公开 Dashboard 局部界面作为真实产品证据。
- 首屏列出已公开支持的七个 Agent 框架。

### 2. Enterprise Scenario Lab

产品页使用独立的 `AgentGuardEnterpriseScenarioLab`，首页只保留业务可读的边界演示：

- 客户续约分析、生产事故响应、供应商付款核验三类企业场景；
- 完整轨迹与节点检查；
- DSL 与安全模型协同研判；
- `ALLOW · AUDIT · REDACT · DEGRADE · HUMAN_CHECK · LLM_CHECK · DENY`；
- `HUMAN_CHECK` 的批准一次与拒绝分支；
- 键盘场景切换、节点检查与重放；
- SSR 输出完整默认状态，减少动画模式直接显示最终状态。

### 3. 真实产品界面

- Dashboard
- 可视化策略配置
- 策略生成
- 官方点击播放 Demo
- 单一主图与可键盘切换的界面标签，不保留旧两节点 Allow / Deny 卡片

### 4. 核心机制

- 全链建模
- 协同研判
- 精细处置

### 5. 接入与部署

- Hook
- Sidecar
- Gateway
- Runtime
- 私有控制面

### 6. 开放证据与 CTA

只链接可核实的 AgentGuard 代码、安全模型与 NUWA 研究，不展示未经证实的客户、部署、性能或规模数据。

## V3.5 AgentGuard 交互边界运行时

完整实验台改为连续时间轨迹，AgentGuard 控制带贯穿 LLM 与工具调用前后。数据、授权、动作影响分别使用圆形、菱形、方形状态点追踪；模型总结不会清除数据血缘，也不会提升外部指令权限。右侧默认使用业务语言说明正在追踪的对象、边界冲突、处置与业务结果，规则、标签、载荷差异和审计义务进入二级展开。

## V3.6 三层完整版

产品页以保护对象总览开场，依次呈现企业系统传播地图、统一安全影响引擎和任务安全模拟器。系统地图支持按身份、Agent、模型、数据、Memory、工具、MCP 与外部系统筛选和节点检查；统一引擎支持数据流、授权流、动作影响与联合判断切换；模拟器覆盖外发脱敏复检、Memory 指令清理和 Shell 沙箱/生产审批。业务语言始终优先，内部标签、传播方式和控制阶段按需展开。

## V3.7 企业安全体系关系

产品页成为任务模拟器、保护对象和安全体系关系的唯一归属。IAM、DLP、API Gateway 与 SIEM 对照表位于接入部署之后、开放证据之前，说明 AgentGuard 补充的任务上下文、委派链、衍生数据血缘、多步轨迹、载荷变化与业务结果。应用场景页不复制 Hook、DSL、统一引擎或任务模拟器。
