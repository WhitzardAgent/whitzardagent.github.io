## Private baseline and update workflow

The first bilingual brief is `baseline`, not a weekly change claim. `scripts/nuwa-review-preview.mjs write` generates Markdown/HTML only under NUWA_PRIVATE_ROOT; `serve` binds127.0.0.1 and exposes only /en and /zh. Default builds cannot import drafts. A source change first creates a candidate signal, then receives scientific review; no automatic publishing exists.
