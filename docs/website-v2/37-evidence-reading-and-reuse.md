## 数据与失效规则

- `reportedUncertainty` 保留原始字符串、类型、方法、水平和样本说明；未知字段保持空。
- `sampleCounts` 区分任务/样本分母、独立运行与尝试；原导出列语义不变，补充列追加。
- 接受决定与发布处置分别保留，暂缓项不会从审核历史消失。
- 单项解读指纹绑定实际阅读资源 URL / SHA、来源元数据及来源版本捕获包；专题另绑定完整结果集合及监测组。
- 指纹变化后标记待复核，停止进入新搜索综合或测量比较；历史快照保留。
- 欺骗专题完整集合为 108 条条件，其中 103 条零值；勒索子集 36 条中 31 条为零，整体范围 0–57%，非零子集才是 3–57%。逐项结果 ID 与计算规则一并保留。
- 日期分别使用模型发布、实际评测、证据公开/捕获；缺失评测日期不推断。
