# 41｜NUWA Index 评测平台

2026-11-01 用户批准完整实施和上线。本版覆盖 22、38、40 中关于知识库主定位、Trend 默认首页和仅本地交付的历史规则；不改变数据、研究审核或后续批次发布授权。

## 定位与任务

NUWA Index 为前沿 AI 安全评测与风险追踪平台，围绕模型安全比较、风险趋势、NUWA 持续标准化评测与外部结果汇聚组织。平台先上线，本次不运行新实验、不设置定时任务。

主导航为总览、模型比较、风险趋势、NUWA 评测、外部评测、研究与方法。首页顺序为首屏、比较预览、六主题、NUWA 计划、外部评测、研究解读、方法与版本。公司入口精简仅作用于 Index，其他产品页保持原有导航。

首页不内联完整目录或全部图表。模型比较通过静态协议组 JSON 按需读取，保留默认静态表格、SVG、CSV；旧 /compare/ 继续比较测量协议。旧查询/锚点通过客户端进入 research 工作台并保留参数；无 JavaScript 的总览提供显式旧视图链接，各独立页仍静态可读。

## 数据和比较

src/data/nuwa-index/index.ts 是有效公开数据唯一入口；当前证据为 2026-10-29.1。平台版本 1.0.0 与证据快照分开，platform-release.json 记录实际构建提交，界面变更不生成实验结果或改写历史。

模型选择以结果身份保留配置，不将来源缺失变成零分。描述性数值排序不赋予安全名次；comparisonPermissions 继续决定严格比较与纵向连线。默认 CyberGym 101 共同任务、2M token 为描述性组。筛选、表格、图表与下载使用同一投影。

NUWA 计划均为筹备中；publishedRuns 为空。发布的未来批次必须具备协议版本、系统、结果引用、任务/脚手架/配置哈希、时间、计分版本与样本状态，并核对结果执行方。原方法作者、原始实验方、转引报告与 NUWA 整理身份分开。
