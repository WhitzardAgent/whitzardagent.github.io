# 09｜中英文核心文案

## 公司定位

中文：

> Whitzard 构建面向企业智能体的安全基础设施，覆盖上线前评测、运行时控制、安全运营与持续优化。

English:

> Whitzard builds security infrastructure for enterprise AI agents, spanning pre-deployment evaluation, runtime control, security operations, and continuous improvement.

## Hero

中文标题：

> 守其边界，行其智能

中文说明：

> 让智能体在安全边界内自主行动。统一评测、理解并控制模型推理、工具调用、身份权限与数据流转。

English title:

> Secure autonomy, by design.

English description:

> Evaluate, govern, and protect AI agents across reasoning, tool use, identity, and data flow—without removing the autonomy that makes them valuable.

## 产品价值

中文：

> 覆盖智能体完整运行过程的统一安全控制层

English:

> One security control layer across the full agent runtime.

## 新型风险

中文：

> 风险不只存在于模型说了什么，也存在于智能体下一步会做什么。

English:

> The risk is not only in what the model says. It is in what the agent does next.

## 三链技术

思维链：

> 在行动发生前识别并纠正高风险推理。

> Identify and correct unsafe reasoning before it becomes action.

行为链：

> 关联跨步骤、跨工具和跨智能体的组合风险。

> Reason over multi-step, cross-tool, and cross-agent behavior.

数据链：

> 追踪敏感数据的来源、用途、流向和外泄边界。

> Track where sensitive data comes from, how it is used, and where it flows.

> Research discovers the risk. Product controls it in the real world.
