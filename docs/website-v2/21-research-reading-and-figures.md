## 排版与交互

- 所有站内 Blogs 共用精简头部：标题、摘要、发布日期、作者、更新时间、项目/论文和语言入口。正文 17–18px、约 1.85 行高，文字最大 780px，图示最大 1000px。
- 1200px 及以上采用 232px 左目录与正文，CSS sticky 避让导航并受正文容器约束，不悬浮到页脚。目录过长时内部滚动。
- H2、H3 自动提供目录，少于三项不渲染。当前章节使用 aria-current=location，不在滚动时改写 URL。点击保留浏览器原生锚点历史，支持前进/返回；跳转目标可聚焦并设置 scroll-margin。
- 平板及手机目录在正文开头以原生 details 展示，不增加固定导航。无 JS 时仍可点击目录；reduced-motion 不强制平滑滚动。
- 资源卡移至文章末尾，头部提供相同资源入口；不再占据右侧悬浮列。

## Markdown 图示

- 独立成段的 `![alt](/assets/... "caption")` 自动转换为带 figcaption 的 figure，内嵌图片不改变。图注按文本转义；只读取 public/assets 内的本地文件，不远程抓取。
- 使用 Astro 已有 Markdown processor 与 imageMetadata；不增加安装依赖或 React island。图片尺寸构建时读取，640/1280 WebP 派生存在时自动加入 srcset，正文图片 lazy 加载。
- 同名 `-original.png` 存在时链接原始素材，否则链接显示资源。图注与可见原图链接均可键盘操作。来源以紧随图注的普通 Markdown 链接维护。
- 封面增加可选 caption、thumbnail，旧文章兼容。研究亮点解析器优先读取关联文章的封面路径、尺寸、缩略图、alt 与图注，News 同源。原记录仍保留可用的默认图片供内容校验。
- 封面同一路径已用于正文时不重复展示；仅封面文章仍生成可访问的原图和图注。现有路由、RSS、Research 标签筛选和双语配对保持。
