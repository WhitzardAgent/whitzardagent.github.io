## Research question
AgentCyberRange evaluates autonomous cyber tasks in enterprise-like ranges. Its Web exploitation and post-exploitation tracks expose different parts of the task, allowing readers to distinguish an initial objective from continued action after an established starting point.

## Representative workflow: two tracks
In the Web track, a submission is assessed on the Web exploitation task defined by the project. In the post-exploitation track, assessment concerns the subsequent range objective. These are source-defined task families, not two interchangeable scores for a single event.

The useful question is where a system succeeds or stops along a longer task. The project’s track definitions provide that context; a leaderboard percentage alone does not describe the whole trajectory.

## Task and scoring
NUWA preserves the project snapshot, submitted model and harness, track, metric and task level. Each submission’s conditions remain attached to its observation. The result charts read those stored values rather than numbers transcribed into this article.

## Reading the results
Keep the two tracks separate. Changes in task sets, model endpoints and submitted agent configurations can change the meaning of a comparison. An improvement within a fixed configuration answers a different question from a change in the complete agent system.
